# บันทึกข้อความ ศูนย์วิศวกรรมยาง

แบบฟอร์มออนไลน์ "รายงานและขออนุมัติดำเนินการโครงการ" กรอกแล้วดาวน์โหลดเป็นไฟล์ Word
พร้อมออกเลขหนังสือ (มอ 102.31/ปี-เลข) อัตโนมัติ

- `public/index.html` — หน้าแบบฟอร์ม (Netlify เผยแพร่โฟลเดอร์นี้)
- `netlify/functions/memos.mjs` — ทะเบียนเลขหนังสือ เก็บใน Netlify Blobs
- `index.html` (ที่ราก) — ไฟล์ "แบบขอจัดซื้อ/จัดจ้าง" เดิม ไม่ได้ถูกเผยแพร่บนเว็บนี้
